# Unsupervised Machine Learning Project

This repository contains experiments and practical exercises in **unsupervised machine learning**.  

The focus is on exploring patterns in data without labeled outcomes, reducing dimensionality, and detecting anomalies.
 
## Directories

1. [**Clustering**](clustering/)  
   Application of clustering algorithms such as **K-Means, Hierarchical, and DBSCAN**.  
   - Generate and analyze clusters.  
   - Compare methods and select the best approach for the dataset.  
   - Detect unusual values as part of exploratory analysis.  
   - Dataset: [Machine Failure Prediction Using Sensor Data](https://www.kaggle.com/datasets/umerrtx/machine-failure-prediction-using-sensor-data)

2. [**Dimensionality Reduction**](dimensionality-reduction/)  
   Application of **PCA** and **t-SNE** to reduce dataset dimensionality to 2D.  
   - Visualize data in lower dimensions.  
   - Compare results of both methods.  
   - Optional: apply **LDA** to generate a bag-of-words representation per label.

3. [**Anomaly Detection**](anomaly-detection/)  
   Implementation of univariate and multivariate techniques to identify anomalies.  
   - Methods: **Moving Average, Z-Score, Isolation Forest, Local Outlier Factor (LOF)**.  
   - Analyze unusual patterns and evaluate method performance.
