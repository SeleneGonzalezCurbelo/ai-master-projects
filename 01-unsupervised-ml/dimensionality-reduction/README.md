# Dimensionality Reduction: PCA and t-SNE

This project explores the application of **dimensionality reduction algorithms** to transform high-dimensional data into a 2D representation for visualization and analysis. 

The main goal is to compare the effectiveness of **PCA** and **t-SNE** in preserving the structure of the dataset and to analyze which technique provides better insights.

## General Objective
Apply dimensionality reduction techniques (PCA and t-SNE) to reduce a dataset to two dimensions, visualize the results, and compare the outcomes to identify the most suitable approach.  

---

## Objectives
- Understand the theoretical foundations of **t-SNE** and **PCA**.  
- Apply both methods for dimensionality reduction and visualize the results.  
- Compare the reduced spaces generated by PCA and t-SNE.  
- Apply **LDA (Latent Dirichlet Allocation)** to represent the dataset as a bag of words per label.
