# Clustering Techniques

This project explores and applies different **clustering algorithms** to identify meaningful groupings and unusual values in real-world datasets.  

The goal is to evaluate the performance of various clustering methods and determine the most suitable approach for the given data.  

## Objectives
- Understand the clustering methods: **K-Means**, **Hierarchical Clustering**, and **DBSCAN**.  
- Generate and analyze cluster groupings using the selected methods and perform a comparative evaluation.  
- Investigate an additional clustering technique and apply it to a specific use case.  
- Perform automatic detection of unusual values based on clustering results.  

---

## Dataset
The dataset used in this project is available on Kaggle:  
[Machine Failure Prediction using Sensor Data](https://www.kaggle.com/datasets/umerrtx/machine-failure-prediction-using-sensor-data)  

It contains sensor readings collected from multiple machines with the goal of predicting machine failures in advance. The dataset includes a variety of sensor measurements along with recorded machine failure events.  

---

## Methodology
1. **Data preprocessing**: cleaning, normalization, and preparation for clustering.  
2. **Clustering application**: applying K-Means, Hierarchical, and DBSCAN algorithms.  
3. **Comparative analysis**: evaluation of the results using metrics such as silhouette score and cluster interpretability.  
4. **Outlier detection**: identification of unusual values through clustering behavior.  
5. **Case study**: investigation of an additional clustering approach applied to the dataset.

## Key Findings
- **Hate comments** tend to be longer and contain more recognized entities (55.56% vs. 34.91%).  
- Hate messages mention **specific people** more often (11.11% vs. 8.49%).  
- Structural differences in gender and number: more masculine singular words in hate messages.  
- Most frequent lemmas:
  - **Hate**: *pp, responsible, clown, master, sánchez, communist, fascist, church, bishop, priest*.  
  - **Non-hate**: *thing, happen, life, madrid*.
