# Anomaly Detection

This project focuses on the application of **anomaly detection techniques** to identify unusual patterns within a dataset.  

The main goal is to analyze whether anomalies exist by applying both **univariate** and **multivariate** approaches.

## Objectives
- Understand and implement the following anomaly detection methods:  
  - **Moving Average**  
  - **Z-Score**  
  - **Isolation Forest**  
  - **Local Outlier Factor (LOF)**  
- Apply each technique to the dataset and analyze the detection of unusual values.  
- Compare the performance of univariate and multivariate methods.

---

## Description
The project requires completing the provided notebook by:  
1. Implementing each anomaly detection technique.  
2. Visualizing and interpreting the detected anomalies.  
3. Explaining the differences in behavior between statistical methods (e.g., moving average, Z-Score) and machine learning-based methods (e.g., Isolation Forest, LOF).
